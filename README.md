A tiny deterministic program for the make.fun competition
[The 3 AM Excuse](https://make.fun/c/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878).

It writes one line (under 200 characters) to `/output/entry.txt`: the excuse a
hardware wallet gives for refusing to sign a transaction at 3 AM. The wallet's
own screen asks for confirmation while the owner's shaking 3 AM thumb begs for
help, and the device refuses to sign what looks like a ransom note.

Run it with `python3 main.py`. Every run writes the exact same bytes.
